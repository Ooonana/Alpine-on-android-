# Security reports

This recovery project does not publish a dedicated security mailbox or external security website.

For ordinary, non-sensitive bugs, use the repository issue tracker:

https://github.com/Ooonana/Alpine-on-android-/issues

Do not send reports to legacy support addresses found in historical recovered material; those addresses are not project support contacts.

If a report contains credentials, private data, or exploit details that should not be public, do not paste those details into a public issue. Use a private GitHub security-reporting channel if one is available for the repository, or contact the repository owner through GitHub first without publishing the sensitive details.
